# Images Folder

Add your images here and update the corresponding components.

## Required Images

### 1. Avatar (About Section)
- **File:** `avatar.jpg` or `avatar.png`
- **Size:** 400x400px (square)
- **Usage:** Your professional headshot
- **Update in:** `src/components/About.js`

### 2. Project Screenshots
Add a screenshot for each project:

| File | Project | Size |
|------|---------|------|
| `naf-pft-sys.jpg` | NAF PFT System | 800x500px |
| `hms.jpg` | Hospital Management System | 800x500px |
| `softtouch.jpg` | SoftTouch | 800x500px |
| `stop-clock.jpg` | Stop Clock | 800x500px |
| `digital-clock.jpg` | Digital Clock | 800x500px |
| `friendlists.jpg` | FriendLists | 800x500px |
| `loginweb.jpg` | Login Web | 800x500px |

**Update in:** `src/components/Projects.js`

### 3. Hero Background (Optional)
- **File:** `hero-bg.jpg`
- **Size:** 1920x1080px
- **Usage:** Optional background for hero section
- **Update in:** `src/styles/custom.css` or `src/components/Hero.js`

## How to Take Screenshots

1. Open your project in browser
2. Press `F12` → Toggle device toolbar → Set to 1440x900
3. Use browser dev tools screenshot or press `Ctrl+Shift+S` (Chrome)
4. Crop to 800x500px

## Or Use Placeholder Images

If you don't have screenshots yet, the code uses placeholder services by default:
- `https://placehold.co/800x500/1a1a2e/6366f1?text=Project+Name`

Just replace the placeholder URLs with your actual image paths once ready.
